# House Price Prediction

## Project Overview

This project explores house price prediction using machine learning techniques. It aims to understand the factors influencing house prices and build a model to estimate prices from housing data.

## Objectives

- Explore and clean the dataset.
- Perform exploratory data analysis (EDA).
- Identify important features associated with house prices.
- Train and evaluate a machine learning regression model.

## Tools and Technologies

- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Workflow

1. Data loading and preprocessing
2. Exploratory data analysis
3. Feature selection and preparation
4. Model training
5. Model evaluation and interpretation

## Project File

- `House_Price_Prediction_Project.ipynb` — notebook containing the analysis and implementation.

## How to Run

Open the notebook in Google Colab or Jupyter Notebook and execute the cells in order. Install any required libraries if prompted.
